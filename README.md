# Office Network Design & Troubleshooting using Cisco Packet Tracer

## 📌 Project Overview

This project demonstrates the design, configuration, and troubleshooting of a small office network using **Cisco Packet Tracer**.

The network connects two departments:

- **ACCOUNTS**
- **DELIVERY**

Each department contains two PCs and one printer. The departments are connected through switches and a router to enable communication between the two networks.

The project uses the given network address **192.168.40.0** and demonstrates practical concepts such as **IP addressing, subnetting, routing, switching, connectivity testing, and network troubleshooting**.

---

## 🎯 Project Objectives

- Design a functional office network topology.
- Connect ACCOUNTS and DELIVERY departments.
- Configure IP addresses and subnet masks.
- Calculate and implement appropriate subnets.
- Configure router interfaces and default gateways.
- Connect network devices using appropriate cables.
- Test connectivity between departments.
- Troubleshoot common network connectivity issues.
